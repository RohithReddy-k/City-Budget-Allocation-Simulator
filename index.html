🏛️ The Municipal Problem Statement

Smart City Decision Support

Municipal corporations operate under strictly bounded annual capital budgets. Every fiscal year, city councils face competing demands across vital public domains: Roads, Sanitation, Healthcare, Education, Water Supply, Environment, and Public Infrastructure.

Traditional municipal budgeting often relies on arbitrary political horse-trading, subjective historical increments, or unscientific heuristics. The City Budget Allocation Simulator transforms this process by formulating capital budgeting as a rigorous Constrained 0/1 Knapsack Optimization Problem, maximizing total societal welfare while strictly respecting statutory constraints.

🧮 The Algorithm: 0/1 Knapsack Variant using Dynamic Programming

Exact Global Optimum

Each candidate project is modeled with:

  • Weight \(w_i\): Project cost in Indian Crores (₹ Cr).
  • Value \(v_i\): Social impact score (1 to 100) reflecting civic benefit.
  • Capacity \(W\): Total municipal budget envelope in ₹ Crores.

Core Recurrence Relation:

DP[i][b] = max( DP[i - 1][b], DP[i - 1][b - cost[i]] + impact[i] )

Simplified Principle:

"For every project, the simulator evaluates two choices:
1. Include the project (consume cost, gain impact).
2. Exclude the project (preserve remaining budget).
Dynamic Programming stores previously calculated results in a state matrix to avoid redundant sub-computations and guarantee the mathematically optimal combination in \(O(N \cdot W)\) time."

Handling Crores and Decimal Precision:

To prevent unnecessarily large arrays, the algorithm detects decimal precision and discretizes values using a dynamic scaling factor (\(\text{Scale} \in \{1, 10, 100\}\)). For a typical city budget of ₹100 Cr with 1 decimal place, capacity is scaled to 1000, calculating the optimal global solution in under 2 milliseconds.

🏗️ Object-Oriented Architecture (OOP Structure)

Modular JavaScript Architecture

The application follows strict Object-Oriented design principles with modular classes:

📦

class Project

Encapsulates ID, name, category, cost, impactScore, priority, mandatory flag, status, and getEfficiency() method.

💰

class Budget

Manages totalBudget, usedBudget, remainingBudget, and tracks utilization percentages dynamically.

⚖️

class Constraint

Enforces statutory budget ceilings, category floors/caps, and mandatory project mandates.

📈

class BudgetAllocation

Contains selectedProjects, rejectedProjects, totalCost, totalImpact, categoryBreakdown, and DP table summaries.

🎮

class BudgetSimulator

Main coordinator running DP optimizations, scenario comparisons, trade-off analysis, and LocalStorage persistence.
